# Closet Studio v5

Esta versión mantiene `closetStudioDB`, `garments`, `cs_looks` y `cs_profile`. Reemplaza los archivos del mismo repositorio y conserva la misma URL.

## Cambios
- Selección obligatoria de una prenda base en Inspírame y opcional en Combinar/Reuniones.
- Puntuación por armonía de color, estilo, tendencias y variedad; penaliza repetir la sugerencia anterior.
- Colores base Azul y Verde restaurados.
- Cuatro plantillas ilustradas aportadas por el usuario, elegidas según la estructura del look.
- Capas de color por camisa, chaqueta, suéter, pantalón, zapatos y corbata.
- Importación de respaldos JSON compatible con versiones anteriores.

La lógica es un recomendador local basado en reglas. No llama una API generativa externa.
