# Closet Studio v3

## Actualización sin perder las prendas
Sube el contenido de esta carpeta a la raíz del mismo repositorio y conserva exactamente la misma URL de GitHub Pages. Esta versión mantiene `closetStudioDB`, el almacén `garments`, `cs_looks` y `cs_profile`, por lo que puede leer los datos de las versiones anteriores guardados en el mismo navegador y origen.

Reemplaza `index.html`, `styles.css`, `app.js`, `sw.js`, `manifest.webmanifest`, `README.md` y `icons`. No borres los datos del sitio en Safari. Antes de actualizar, usa **Perfil > Exportar respaldo**.

El “Asesor IA” incluido es un agente local basado en reglas y estadísticas del clóset. No envía fotografías a servicios externos. Para una IA generativa real se necesitaría un backend seguro que mantenga la clave de API fuera de GitHub Pages.
