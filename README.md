# Closet Studio v4

Sube el contenido de esta carpeta a la raíz del mismo repositorio y conserva la misma URL de GitHub Pages. La versión mantiene `closetStudioDB`, `garments`, `cs_looks` y `cs_profile`.

## Restaurar el respaldo
1. Abre **Perfil**.
2. En **Respaldo**, selecciona el archivo JSON.
3. Elige **Combinar sin duplicados** para conservar datos actuales, o **Reemplazar** para restaurar únicamente el respaldo.
4. Pulsa **Importar respaldo**.

La importación valida el arreglo `garments`, conserva imágenes Base64, evita IDs duplicados y restaura looks y perfil cuando están presentes.
