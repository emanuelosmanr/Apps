# App Finanzas Personales 1.0

Sube todos los archivos a la raíz del repositorio y conserva `assets/icons`.

Perfiles iniciales: Administrador y Emanuel. Ambos usan inicialmente la contraseña indicada durante la creación de esta versión. Cámbiala luego de iniciar sesión.

En el primer inicio de cada perfil, abre Datos > Código de recuperación y guárdalo fuera del dispositivo. Ese código permite establecer una contraseña nueva sin perder la información. La aplicación no puede recuperar una contraseña sin el código.

Cada perfil nuevo comienza con salario 0, sin deudas, gastos, movimientos ni proyectos.
